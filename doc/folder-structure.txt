===============================================================================
                        F O L D E R   S T R U C T U R E
===============================================================================
Where every file goes. One Laravel app. All UI under frontend/. All domain
under modules/. Contracts live inside the module, not as a second package.

Placeholder modules: alpha, beta. Real module names live in Features-list.txt.

If this file disagrees with architecture-map.txt, architecture-map wins on
shape. This file wins on paths.


-------------------------------------------------------------------------------
1 - TOP LEVEL
-------------------------------------------------------------------------------

    /

    │   ├── Http/Middleware/      Cross-cutting HTTP: auth, ids, limits
    │   └── Providers/            Registers each module. One line each

    │   ├── view.php              Points at frontend/storefront/views

    │
    ├── routes/                   Host mounts. Defines almost nothing
    │   ├── api.php               Mounts /api/v1. Modules own the routes
    │   └── web.php               Mounts storefront + /admin catch-all
    │
    ├── frontend/                 ALL UI. See part 3
    ├── modules/                  ALL DOMAIN CODE. See part 2
    │
    ├── packages/
    │   ├── shared/               Tiny kernel. No Illuminate
    │   │   └── src/              Clock, Ids, Money, …
    │   └── platform/             Machinery. No domain knowledge
    │       └── src/
    │           ├── PlatformServiceProvider.php
    │           ├── Http/         Host-wide HTTP helpers (e.g. media)
    │           └── Infrastructure/
    │               └── Persistence/
    │                   └── Bootstrap/   platform + reporting schemas
    │
    ├── database/                 STAYS EMPTY. Do not put schema here
    │   └── migrations/           Empty on purpose
    │
    ├── public/                   Web root: index.php + built JS/CSS

    ├── tests/                    Host tests (not module tests)

    └── doc/                      architecture, folders, modules, workflow,
                                  tech-stack, Features-list


EACH FOLDER (one line)

    app/            Host glue. Never a table, never a business rule
    bootstrap/      How Laravel boots. Exception shape lives here
    config/         Env-driven settings. No domain
    routes/         Mounts other people's routes. Empty of rules
    frontend/       Every screen a human sees
    modules/        Every capability. One folder = one module
    packages/shared Tiny types used by every module (money, ids, clock)
    packages/platform  Bus, outbox, media, problem details. No product
    database/       Empty trap. Real SQL is in Infrastructure/Persistence
    public/         What the web server exposes
    media/          Files on disk. Prefix from .env so projects do not mix
    resources/      Empty trap. Templates are in frontend/
    storage/        Framework scratch space. Do not put product files here
    tests/          Host-level tests. Each module has its own tests/
    doc/            How the system is shaped. Read these first

2 - ONE MODULE
-------------------------------------------------------------------------------
Always the same five code folders. Contracts is public. The other four are
private. docs/ and tests/ sit beside src/.

    modules/alpha/
    ├── composer.json                 This module as a Composer package
    ├── docs/                         THIS MODULE'S DOCUMENTATION
    │   ├── README.md                 What this module is
    │   ├── folder-structure.md       This module's tree
    │   ├── database.md               Schema, tables, relations
    │   └── api.md                    HTTP, contracts, events
    ├── src/
    │   ├── AlphaServiceProvider.php  Loads this module's routes + migrations
    │   │
    │   ├── Contracts/            ◄── PUBLIC. Others may use this only
    │   │   ├── AlphaApi.php          Questions other modules may ask
    │   │   ├── Dto/                  Plain readonly data. Never Eloquent
    │   │   └── Events/               Past-tense facts. Immutable
    │   │
    │   ├── Api/                  ◄── PRIVATE. HTTP in and out
    │   │   ├── Routes/api.php        JSON routes. No module name in URL
    │   │   ├── Controllers/          Thin. No rules
    │   │   ├── Requests/             Shape of the HTTP body only
    │   │   └── Resources/            JSON shape of the reply
    │   │
    │   ├── Application/
    │   │   ├── CreateWidget/         ONE FOLDER PER USE CASE
    │   │   │   ├── CreateWidgetCommand.php
    │   │   │   ├── CreateWidgetHandler.php
    │   │   │   └── CreateWidgetResult.php
    │   │   ├── Ports/                Interfaces this module needs
    │   │   └── Listeners/            Reactions to other modules' events
    │   │
    │   ├── Domain/                   PURE PHP. Rules and vocabulary
    │   │   ├── Widget.php            No Illuminate, no ORM, no now()

    │   │   └── Rules/
    │   │
    │   └── Infrastructure/
    │       ├── Persistence/          ALL DATABASE CODE FOR THIS MODULE
    │       │   ├── Bootstrap/        Schema, roles, grants (SQL)
    │       │   ├── Models/           Eloquent. Here only
    │       │   ├── Repositories/     Map models ↔ domain objects
    │       │   ├── Migrations/       Tables in this schema only
    │       │   ├── Seeders/          Seed data for this schema only
    │       │   └── Factories/        Test/demo builders for this schema
    │       ├── Adapters/             Outside vendors, behind Ports/
    │       ├── ReadModels/           Projections this module maintains
    │       └── AlphaApiImpl.php      Implements Contracts/AlphaApi
    │
    └── tests/
        ├── use-cases.txt             Living Use Case Cards. Step 1.
        ├── Unit/
        │   ├── Domain/               Pure PHP rules. No Laravel. No DB
        │   └── Application/          Handlers. In-memory fakes. Fake outbox
        ├── Feature/
        │   ├── Api/                  HTTP front door. JSON shape only
        │   ├── Infrastructure/       This schema only. SQLite mapping ok
        │   └── Listeners/            Event → row. Run twice. Same state
        └── Architecture/             This module's layers do not mix

    modules/beta/ is the same shape.


EACH FOLDER (one line)

    composer.json     Declares this module as a package
    docs/             Human docs. Update in the same turn as code
    src/              All PHP for this module
    Contracts/        The only door other modules may walk through
    Api/              HTTP. Format and transport. No decisions
    Application/      One folder per use case. Orchestrates. Does not decide
    Domain/           The rules. Pure. Testable with no database
    Infrastructure/   Adapters: database, mail, payments, files
    Persistence/      Every SQL file, model, seeder, factory for this schema
    Bootstrap/        CREATE SCHEMA + roles + grants
    tests/            This module only. Never another module's tables
    use-cases.txt     Living Use Case Cards. Write and update at Step 1
    Unit/Domain       Pure PHP rules. No Laravel. No DB
    Unit/Application  Handlers. In-memory fakes. Fake outbox
    Feature/Api       HTTP shape. No business rules
    Feature/Infrastructure  Persistence in this schema
    Feature/Listeners Outbox reaction. Assert the row. Run twice
    Architecture/     This module's layers do not mix


THE RULE THIS SHAPE ENCODES
    Another module may reference `Modules\Alpha\Contracts\` and nothing else
    under `Modules\Alpha\`. Domain depends on nothing. Infrastructure
    implements interfaces Application declares. All database files live in
    Infrastructure/Persistence/ of the owner (platform or a module).

3 - FRONTEND
-------------------------------------------------------------------------------

    frontend/
    ├── storefront/               PUBLIC site. Server-rendered. Crawlers see it
    │   ├── Http/                 Thin controllers. Contracts only
    │   ├── routes/web.php        Pages. Mounted by host routes/web.php
    │   ├── views/                Blade templates
    │   ├── css/                  Public CSS (no UI kit chosen yet)
    │   ├── islands/              React, only where a part is interactive
    │   │   └── main.tsx          Finds [data-island] and mounts them
    │   └── vite.config.ts        Builds to public/build
    │
    └── admin/                    PRIVATE. React app behind a login
        ├── src/
        │   ├── main.tsx          SPA entry
        │   ├── routes/           Client URLs (TanStack Router)
        │   ├── api/              Typed calls to /api/v1
        │   └── components/       Screens and widgets
        ├── index.html
        └── vite.config.ts        Builds to public/build/admin


EACH FOLDER (one line)

    storefront/     HTML in the first response. SEO and share previews
    Http/           Composition only. Calls contracts. No tables
    views/          Blade. Not in resources/views
    islands/        Small React pieces on an otherwise static page
    admin/          Operator UI. Never holds a rule or a credential
    admin/src/api/  Fetch /api/v1. Nothing else


HOW THE TWO ARE WIRED

    Storefront   config/view.php → frontend/storefront/views
                 Blade calls contracts in-process
                 @vite('frontend/storefront/islands/main.tsx')

    Admin        Route::view('/admin/{any?}', 'admin')
                 Bundle in public/build/admin (not public/admin —
                 that path would steal the /admin URL)

    Data         Blade → contracts. React → HTTP /api/v1
                 Neither knows a table or a module name

4 - ENFORCING THE BOUNDARY
-------------------------------------------------------------------------------
Deptrac collects each subfolder. Never the module root.

    AlphaContracts       modules/alpha/src/Contracts/
    AlphaDomain          modules/alpha/src/Domain/
    AlphaApplication     modules/alpha/src/Application/
    AlphaApi             modules/alpha/src/Api/
    AlphaInfrastructure  modules/alpha/src/Infrastructure/

    AlphaDomain:         [ Shared ]
    AlphaApplication:    [ AlphaDomain, Shared, BetaContracts ]
    AlphaInfrastructure: [ AlphaDomain, AlphaApplication, Shared, Platform ]
    AlphaApi:            [ AlphaApplication, Shared ]
    AlphaContracts:      [ Shared ]
    Frontend:            [ Shared, AlphaContracts, BetaContracts ]

MISTAKE
    A collector on `modules/alpha/src/.*` matches all five folders, the
    layers collapse, and Deptrac stays green while the rules mean nothing.


-------------------------------------------------------------------------------
5 - CONTRACTS AS A FOLDER, NOT A PACKAGE
-------------------------------------------------------------------------------
Callers depend on a namespace, not on a second Composer package. Deptrac
blocks internals. If a module is extracted later, move Contracts/ out and
keep the same namespace — no `use` statement changes.
