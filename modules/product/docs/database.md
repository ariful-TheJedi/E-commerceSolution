Schema: `product` on database `ecommercesolution`.

Postgres stores the name in lowercase (unquoted CREATE DATABASE).
Source of columns: `database-design.txt` in this folder.
SQL: `../src/Infrastructure/Persistence/Bootstrap/schema.sql`

Roles: `product_owner` (DDL) · `product_app` (DML). No grants on other schemas.

Applied 2026-08-31: platform + reporting + product (22 tables).

Feature 6 adds nullable weight_g, length_mm, width_mm, and height_mm columns
to products and product_variants. Product values are catalog defaults;
variant values override them. products.shipping_class is an optional label
only. Shipping rates, zones, and carriers are outside this module.

Feature 7 uses attributes, attribute_options, and product_attribute_values.
Definitions hold type and facet metadata; options hold optional swatch data;
assignments may target a product or variant.

Feature 9 uses product_media for ordered image/video paths, optional
variant mapping, and one primary image per product. digital_files stores
download paths plus catalog limits and expiry days. File bytes and download
entitlement are owned by the platform media disk and Orders respectively.

Feature 10 uses categories and product_categories for nested trees and
membership, with one canonical category per product. tags and product_tags
provide flat labels. collections, collection_rules, and collection_products
support manual or automatic catalog grouping without inventory or order data.

Feature 11 uses product_relations for manual product-to-product links. The
allowed kinds are related, upsell, cross_sell, alternative, and fbt. The
composite key makes repeated links idempotent, and self-links are rejected.

The sample catalog is generated by ProductCatalogFactory and is loaded by
DatabaseSeeder only in local/staging environments or when PRODUCT_SEED=true.
The additive migration under Infrastructure/Persistence/Migrations must be
run by the actual PostgreSQL owner before seeding an existing database.

Existing database upgrade and seed:

	psql -U <schema-owner> -d ecommercesolution \
		-f modules/product/src/Infrastructure/Persistence/Migrations/20260903_000001_add_catalog_labels.sql
	PRODUCT_SEED=true php artisan db:seed --class=DatabaseSeeder

The migration is additive and the factory is idempotent. Do not run
PRODUCT_SEED=true against production unless demo catalog data is explicitly
required there.
