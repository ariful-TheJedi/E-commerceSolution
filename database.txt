================================================================================
E-COMMERCE DATABASE DESIGN
================================================================================
Style       : Single database (modular monolith)
DB engine   : PostgreSQL recommended (SQL Server also fine)
Strategy    : TenantId stub from day 1 (default tenant) for future SaaS
Naming      : snake_case tables; module prefixes optional (shown without prefix)


================================================================================
1. DESIGN PRINCIPLES
================================================================================

1. Soft delete where business data must be recoverable (products, users, coupons)
2. Never hard-delete paid orders / payments — use status flags
3. Audit columns on mutable business tables:
     created_at, created_by, updated_at, updated_by, is_deleted, deleted_at
4. Money as decimal(18,2) + currency_code (ISO) — avoid float
5. Stock changes only via stock_movements (audit trail) — not silent UPDATEs alone
6. Orders snapshot product name/price at purchase time (order_items)
7. Prefer lookup/status enums as smallint or varchar + check constraint
8. All FKs indexed; hot filters (status, created_at, slug, sku) indexed
9. tenant_id UUID NOT NULL DEFAULT '00000000-0000-0000-0000-000000000001'
   on tenant-owned tables (ready for Phase 4)

5. TABLE DEFINITIONS (DETAILED)
================================================================================

────────────────────────────────────────────────────────────────────────────────
A) IDENTITY & ACCESS
────────────────────────────────────────────────────────────────────────────────

tenants
--------
  id              UUID PK
  name            VARCHAR(200) NOT NULL
  slug            VARCHAR(100) NOT NULL UNIQUE
  status          VARCHAR(30) NOT NULL DEFAULT 'active'
  plan_code       VARCHAR(50) NULL              -- P4
  created_at      TIMESTAMPTZ NOT NULL

users
-----
  id              UUID PK
  tenant_id       UUID NOT NULL FK → tenants.id
  email           VARCHAR(255) NOT NULL
  phone           VARCHAR(30) NULL
  password_hash   VARCHAR(255) NOT NULL
  full_name       VARCHAR(200) NOT NULL
  status          VARCHAR(30) NOT NULL DEFAULT 'active'
                  -- active | locked | disabled
  email_verified  BOOLEAN NOT NULL DEFAULT false
  phone_verified  BOOLEAN NOT NULL DEFAULT false
  last_login_at   TIMESTAMPTZ NULL
  created_at      TIMESTAMPTZ NOT NULL
  updated_at      TIMESTAMPTZ NULL
  is_deleted      BOOLEAN NOT NULL DEFAULT false
  UNIQUE (tenant_id, email)

roles
-----
  id              UUID PK
  tenant_id       UUID NULL               -- NULL = system role
  code            VARCHAR(50) NOT NULL    -- owner|manager|support|warehouse|customer
  name            VARCHAR(100) NOT NULL
  UNIQUE (tenant_id, code)

user_roles
----------
  user_id         UUID NOT NULL FK → users.id
  role_id         UUID NOT NULL FK → roles.id
  PRIMARY KEY (user_id, role_id)

refresh_tokens
--------------
  id              UUID PK
  user_id         UUID NOT NULL FK → users.id ON DELETE CASCADE
  token_hash      VARCHAR(255) NOT NULL UNIQUE
  expires_at      TIMESTAMPTZ NOT NULL
  revoked_at      TIMESTAMPTZ NULL
  created_at      TIMESTAMPTZ NOT NULL
  user_agent      VARCHAR(300) NULL
  ip_address      VARCHAR(45) NULL

addresses
---------
  id              UUID PK
  user_id         UUID NOT NULL FK → users.id ON DELETE CASCADE
  label           VARCHAR(50) NULL            -- Home / Office
  full_name       VARCHAR(200) NOT NULL
  phone           VARCHAR(30) NOT NULL
  line1           VARCHAR(255) NOT NULL
  line2           VARCHAR(255) NULL
  city            VARCHAR(100) NOT NULL
  state           VARCHAR(100) NULL
  postal_code     VARCHAR(30) NULL
  country_code    CHAR(2) NOT NULL DEFAULT 'BD'
  is_default_shipping BOOLEAN NOT NULL DEFAULT false
  is_default_billing  BOOLEAN NOT NULL DEFAULT false
  created_at      TIMESTAMPTZ NOT NULL

B) CATALOG
────────────────────────────────────────────────────────────────────────────────

brands
------
  id              UUID PK
  tenant_id       UUID NOT NULL FK → tenants.id
  name            VARCHAR(150) NOT NULL
  slug            VARCHAR(150) NOT NULL
  logo_media_id   UUID NULL FK → media_assets.id
  is_active       BOOLEAN NOT NULL DEFAULT true
  UNIQUE (tenant_id, slug)

categories
----------
  id              UUID PK
  tenant_id       UUID NOT NULL FK → tenants.id
  parent_id       UUID NULL FK → categories.id
  name            VARCHAR(150) NOT NULL
  slug            VARCHAR(150) NOT NULL
  description     TEXT NULL
  image_media_id  UUID NULL FK → media_assets.id
  sort_order      INT NOT NULL DEFAULT 0
  is_active       BOOLEAN NOT NULL DEFAULT true
  UNIQUE (tenant_id, slug)

products
--------
  id              UUID PK
  tenant_id       UUID NOT NULL FK → tenants.id
  brand_id        UUID NULL FK → brands.id
  name            VARCHAR(255) NOT NULL
  slug            VARCHAR(255) NOT NULL
  description     TEXT NULL
  short_description VARCHAR(500) NULL
  product_type    VARCHAR(30) NOT NULL DEFAULT 'simple'
                  -- simple | variant | digital | bundle
  status          VARCHAR(30) NOT NULL DEFAULT 'draft'
                  -- draft | active | archived
  base_price      DECIMAL(18,2) NOT NULL
  compare_at_price DECIMAL(18,2) NULL
  cost_price      DECIMAL(18,2) NULL
  currency_code   CHAR(3) NOT NULL DEFAULT 'BDT'
  tax_class       VARCHAR(50) NULL
  weight_grams    INT NULL
  is_featured     BOOLEAN NOT NULL DEFAULT false
  meta_title      VARCHAR(255) NULL
  meta_description VARCHAR(500) NULL
  published_at    TIMESTAMPTZ NULL
  created_at      TIMESTAMPTZ NOT NULL
  updated_at      TIMESTAMPTZ NULL
  created_by      UUID NULL
  updated_by      UUID NULL
  is_deleted      BOOLEAN NOT NULL DEFAULT false
  UNIQUE (tenant_id, slug)
  INDEX (tenant_id, status)
  INDEX (tenant_id, is_featured)

product_categories
------------------
  product_id      UUID NOT NULL FK → products.id ON DELETE CASCADE
  category_id     UUID NOT NULL FK → categories.id ON DELETE CASCADE
  PRIMARY KEY (product_id, category_id)

product_variants
----------------
  id              UUID PK
  product_id      UUID NOT NULL FK → products.id ON DELETE CASCADE
  sku             VARCHAR(100) NOT NULL
  barcode         VARCHAR(100) NULL
  name            VARCHAR(200) NULL          -- "Red / XL"
  attributes      JSONB NULL                -- {"color":"Red","size":"XL"}
  price           DECIMAL(18,2) NOT NULL
  compare_at_price DECIMAL(18,2) NULL
  cost_price      DECIMAL(18,2) NULL
  weight_grams    INT NULL
  is_default      BOOLEAN NOT NULL DEFAULT false
  is_active       BOOLEAN NOT NULL DEFAULT true
  created_at      TIMESTAMPTZ NOT NULL
  UNIQUE (sku)                              -- or UNIQUE(tenant via join)
  INDEX (product_id)

product_images
--------------
  id              UUID PK
  product_id      UUID NOT NULL FK → products.id ON DELETE CASCADE
  variant_id      UUID NULL FK → product_variants.id
  media_id        UUID NOT NULL FK → media_assets.id
  sort_order      INT NOT NULL DEFAULT 0
  alt_text        VARCHAR(255) NULL
  is_primary      BOOLEAN NOT NULL DEFAULT false

tags
----
  id              UUID PK
  tenant_id       UUID NOT NULL FK → tenants.id
  name            VARCHAR(100) NOT NULL
  slug            VARCHAR(100) NOT NULL
  UNIQUE (tenant_id, slug)

product_tags
------------
  product_id      UUID NOT NULL FK → products.id ON DELETE CASCADE
  tag_id          UUID NOT NULL FK → tags.id ON DELETE CASCADE
  PRIMARY KEY (product_id, tag_id)

C) INVENTORY
────────────────────────────────────────────────────────────────────────────────

warehouses
----------
  id              UUID PK
  tenant_id       UUID NOT NULL FK → tenants.id
  code            VARCHAR(50) NOT NULL
  name            VARCHAR(150) NOT NULL
  is_default      BOOLEAN NOT NULL DEFAULT false
  is_active       BOOLEAN NOT NULL DEFAULT true
  UNIQUE (tenant_id, code)

stock_items
-----------
  id              UUID PK
  tenant_id       UUID NOT NULL FK → tenants.id
  variant_id      UUID NOT NULL FK → product_variants.id
  warehouse_id    UUID NOT NULL FK → warehouses.id
  quantity_on_hand     INT NOT NULL DEFAULT 0
  quantity_reserved    INT NOT NULL DEFAULT 0
  -- available = on_hand - reserved (computed in app or generated column)
  low_stock_threshold  INT NOT NULL DEFAULT 5
  updated_at      TIMESTAMPTZ NOT NULL
  UNIQUE (variant_id, warehouse_id)
  CHECK (quantity_on_hand >= 0)
  CHECK (quantity_reserved >= 0)

stock_movements
---------------
  id              UUID PK
  stock_item_id   UUID NOT NULL FK → stock_items.id
  movement_type   VARCHAR(30) NOT NULL
                  -- purchase_in | sale_out | reserve | release
                  -- adjust | return_in | transfer
  quantity        INT NOT NULL              -- signed: +in / -out
  reference_type  VARCHAR(50) NULL         -- order | return | manual
  reference_id    UUID NULL
  note            VARCHAR(500) NULL
  created_by      UUID NULL
  created_at      TIMESTAMPTZ NOT NULL
  INDEX (stock_item_id, created_at)

D) CART
────────────────────────────────────────────────────────────────────────────────

carts
-----
  id              UUID PK
  tenant_id       UUID NOT NULL FK → tenants.id
  user_id         UUID NULL FK → users.id     -- NULL = guest
  session_id      VARCHAR(100) NULL           -- guest cart key
  coupon_id       UUID NULL FK → coupons.id
  currency_code   CHAR(3) NOT NULL DEFAULT 'BDT'
  expires_at      TIMESTAMPTZ NULL            -- abandoned cart jobs
  updated_at      TIMESTAMPTZ NOT NULL
  created_at      TIMESTAMPTZ NOT NULL
  INDEX (tenant_id, user_id)
  INDEX (tenant_id, session_id)

cart_items
----------
  id              UUID PK
  cart_id         UUID NOT NULL FK → carts.id ON DELETE CASCADE
  variant_id      UUID NOT NULL FK → product_variants.id
  quantity        INT NOT NULL CHECK (quantity > 0)
  unit_price      DECIMAL(18,2) NOT NULL      -- locked when added (or refresh)
  UNIQUE (cart_id, variant_id)


────────────────────────────────────────────────────────────────────────────────
E) ORDERS
────────────────────────────────────────────────────────────────────────────────

orders
------
  id              UUID PK
  tenant_id       UUID NOT NULL FK → tenants.id
  user_id         UUID NULL FK → users.id     -- NULL if guest checkout
  order_number    VARCHAR(30) NOT NULL        -- human readable UNIQUE per tenant
  status          VARCHAR(30) NOT NULL DEFAULT 'pending'
                  -- pending | confirmed | processing | shipped
                  -- delivered | cancelled | returned
  payment_status  VARCHAR(30) NOT NULL DEFAULT 'unpaid'
                  -- unpaid | pending | paid | partially_refunded | refunded | failed
  currency_code   CHAR(3) NOT NULL
  subtotal        DECIMAL(18,2) NOT NULL
  discount_total  DECIMAL(18,2) NOT NULL DEFAULT 0
  shipping_total  DECIMAL(18,2) NOT NULL DEFAULT 0
  tax_total       DECIMAL(18,2) NOT NULL DEFAULT 0
  grand_total     DECIMAL(18,2) NOT NULL
  coupon_id       UUID NULL FK → coupons.id
  coupon_code     VARCHAR(50) NULL            -- snapshot
  shipping_rate_id UUID NULL FK → shipping_rates.id
  shipping_method_name VARCHAR(100) NULL     -- snapshot
  customer_email  VARCHAR(255) NOT NULL
  customer_phone  VARCHAR(30) NULL
  customer_name   VARCHAR(200) NOT NULL
  -- shipping address snapshot (denormalized for history)
  ship_full_name  VARCHAR(200) NOT NULL
  ship_phone      VARCHAR(30) NOT NULL
  ship_line1      VARCHAR(255) NOT NULL
  ship_line2      VARCHAR(255) NULL
  ship_city       VARCHAR(100) NOT NULL
  ship_state      VARCHAR(100) NULL
  ship_postal_code VARCHAR(30) NULL
  ship_country_code CHAR(2) NOT NULL
  billing_same_as_shipping BOOLEAN NOT NULL DEFAULT true
  bill_full_name  VARCHAR(200) NULL
  bill_phone      VARCHAR(30) NULL
  bill_line1      VARCHAR(255) NULL
  bill_line2      VARCHAR(255) NULL
  bill_city       VARCHAR(100) NULL
  bill_state      VARCHAR(100) NULL
  bill_postal_code VARCHAR(30) NULL
  bill_country_code CHAR(2) NULL
  customer_note   VARCHAR(1000) NULL
  internal_note   VARCHAR(1000) NULL
  placed_at       TIMESTAMPTZ NOT NULL
  cancelled_at    TIMESTAMPTZ NULL
  created_at      TIMESTAMPTZ NOT NULL
  updated_at      TIMESTAMPTZ NULL
  UNIQUE (tenant_id, order_number)
  INDEX (tenant_id, status, placed_at DESC)
  INDEX (tenant_id, user_id)

order_items
-----------
  id              UUID PK
  order_id        UUID NOT NULL FK → orders.id ON DELETE RESTRICT
  variant_id      UUID NULL FK → product_variants.id  -- NULL if variant deleted later
  product_id      UUID NULL FK → products.id
  sku             VARCHAR(100) NOT NULL               -- snapshot
  product_name    VARCHAR(255) NOT NULL               -- snapshot
  variant_name    VARCHAR(200) NULL
  unit_price      DECIMAL(18,2) NOT NULL
  quantity        INT NOT NULL CHECK (quantity > 0)
  line_subtotal   DECIMAL(18,2) NOT NULL
  line_discount   DECIMAL(18,2) NOT NULL DEFAULT 0
  line_total      DECIMAL(18,2) NOT NULL
  INDEX (order_id)

returns  (Phase 2)

  UNIQUE (tenant_id, return_number)

9. STOCK RULES (IMPORTANT)
================================================================================

Add to cart / checkout:
  1) Check available = on_hand - reserved
  2) On OrderPlaced (payment pending COD or paid online):
       INSERT stock_movements (reserve)
       UPDATE stock_items.quantity_reserved += qty
  3) On ship / confirm sale:
       movement sale_out; on_hand -= qty; reserved -= qty
  4) On cancel before ship:
       movement release; reserved -= qty

Always write stock_movements — enables audit & dispute resolution.
